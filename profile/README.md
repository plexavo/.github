# Plexavo Labs

**Security tools for developers, startups, and the systems they build.**

Plexavo Labs is an independent security engineering lab building open source tools for cloud, infrastructure, and modern developer environments.

We believe security tools should be **useful, understandable, accessible, and built around real problems**, whether you're an individual developer, a growing startup, or a large organization.

> [!NOTE]
> **Plexavo is our first product. More are coming.**

## Plexavo

**See your cloud. Secure what matters.**

Plexavo is an open source AWS security scanner that turns cloud configuration data into actionable security intelligence.

It finds real AWS misconfigurations and privilege escalation paths, shows how they connect into potential attack paths, and explains what to fix in plain English.

- **Deterministic detection**  
  AI does not decide whether something is a security finding.

- **Attack path aware**  
  Connects individual misconfigurations to show how they can matter together.

- **Local first**  
  Runs using your own AWS credentials. Your cloud data stays on your machine.

- **AI when useful**  
  Optional AI narration makes findings easier to understand, but is never required.

- **Agent friendly**  
  Designed to work with tools such as Claude Code while keeping security sensitive actions read only.

- **Open source**  
  Built in public and open to inspection, contributions, and criticism.

> [!IMPORTANT]
> Plexavo is read only. It never changes your AWS account, and AI never decides what counts as a finding.
